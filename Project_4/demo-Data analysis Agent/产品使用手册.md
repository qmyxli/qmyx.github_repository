## 1. 产品概述

### 1.1 产品简介

电商数据分析Agent智能体是一款企业级的自动化数据分析系统，专为电商行业设计。它能够完成从数据采集、清洗、分析、可视化到报告生成的全流程自动化，帮助用户快速洞察业务数据、发现商业机会。

### 1.2 核心能力

| 能力 | 说明 |
|------|------|
| **数据采集** | 支持CSV、Excel、SQL数据库等多种数据源 |
| **数据清洗** | 自动处理缺失值、异常值、重复值 |
| **深度分析** | 描述性统计、RFM客户细分、趋势分析、相关性分析 |
| **数据可视化** | 销售趋势图、客户细分饼图、相关性热力图 |
| **报告生成** | HTML/Markdown格式分析报告，含业务建议 |
| **SQL数据库** | 支持PostgreSQL、MySQL、SQLite直连查询 |
| **智能工作流** | Plan-and-Execute模式，自动规划并执行分析任务 |

### 1.3 适用场景

- 电商企业日常销售数据分析
- 客户价值评估与细分（RFM分析）
- 销售趋势监控与预测
- 商品关联性分析
- 定期数据报告自动生成

## 5. 核心功能详解

### 5.1 数据采集 (`DataCollector`)

支持三种数据来源:

#### CSV文件

```python
agent.load_data('data/orders.csv', source_type='csv')
```

#### Excel文件

```python
# 通过DataCollector直接加载
from agent.tools.data_collector import DataCollector
collector = DataCollector()
df = collector.collect_from_excel('data/orders.xlsx', sheet_name=0)
```

#### 示例数据（用于测试）

```python
data = agent.load_data('sample', source_type='sample', n_orders=200, n_customers=500)
# 返回3个数据集: orders, customers, products
```

**示例数据字段说明:**

| 数据集 | 字段 | 类型 | 说明 |
|--------|------|------|------|
| orders | order_id | string | 订单编号 |
| orders | customer_id | string | 客户编号 |
| orders | order_date | datetime | 订单日期 |
| orders | total_amount | float | 订单金额 |
| orders | status | string | 订单状态(completed/cancelled/refunded) |
| customers | customer_id | string | 客户编号 |
| customers | age | int | 年龄 |
| customers | gender | string | 性别(M/F) |
| customers | city | string | 城市 |
| customers | signup_date | datetime | 注册日期 |
| products | product_id | string | 商品编号 |
| products | category | string | 品类 |
| products | price | float | 价格 |
| products | stock | int | 库存 |

### 5.2 数据清洗 (`DataCleaner`)

清洗流程包含三个步骤:

```python
# 使用默认策略（自动推断）
df_cleaned = agent.clean_data('orders')

# 使用自定义策略
df_cleaned = agent.clean_data('orders', config={
    'remove_duplicates': True,
    'missing_strategy': {
        'total_amount': 'median',   # 数值列用中位数填充
        'status': 'mode'            # 分类列用众数填充
    },
    'outlier_columns': ['total_amount']  # IQR法处理异常值
})
```

| 步骤 | 方法 | 说明 |
|------|------|------|
| 删除重复值 | `drop_duplicates()` | 完全相同的行 |
| 缺失值处理 | mean/median/mode/zero | 数值列默认中位数，分类列默认众数 |
| 异常值处理 | IQR法 | Q1-1.5*IQR ~ Q3+1.5*IQR |

### 5.3 数据分析 (`DataAnalyzer`)

#### 描述性统计

```python
result = agent.analyze_data('orders', 'descriptive')
# 返回: 数据形状、列名、统计指标、缺失值统计
```

#### RFM客户分析

RFM模型从三个维度评估客户价值:

| 维度 | 含义 | 评分逻辑 |
|------|------|---------|
| **R** (Recency) | 最近一次消费距今天数 | 越小越好（1-5分） |
| **F** (Frequency) | 消费频次 | 越大越好（1-5分） |
| **M** (Monetary) | 消费总金额 | 越大越好（1-5分） |

客户细分规则:

| RFM总分 | 客户类别 |
|---------|---------|
| >= 13 | 高价值客户 |
| 10-12 | 中等价值客户 |
| 7-9 | 低价值客户 |
| < 7 | 流失风险客户 |

```python
rfm_result = agent.analyze_data('orders', 'rfm',
    customer_col='customer_id',
    date_col='order_date',
    amount_col='total_amount')
```

#### 趋势分析

```python
trend_result = agent.analyze_data('orders', 'trend',
    date_col='order_date',
    value_col='total_amount',
    freq='ME')  # 按月聚合（注意: pandas 3.0使用'ME'而非'M'）
```

返回: 每期销售额、环比增长率、移动平均值。

#### 相关性分析

```python
corr_result = agent.analyze_data('orders', 'correlation',
    columns=['total_amount', 'quantity'])  # 可选，默认全部数值列
```

### 5.4 数据可视化 (`DataVisualizer`)

```python
# 销售趋势图（折线图）
path = agent.visualize_data('orders', 'sales_trend',
    date_col='order_date',
    value_col='total_amount')

# 客户细分饼图（需先执行RFM分析）
path = agent.visualize_data('orders', 'customer_segments')

# 相关性热力图
path = agent.visualize_data('orders', 'correlation_heatmap')
```

所有图表保存至 `output/` 目录，分辨率300 DPI，支持中文标注。

### 5.5 报告生成 (`ReportGenerator`)

```python
# HTML报告（推荐，含样式排版）
path = agent.generate_report('html')

# Markdown报告
path = agent.generate_report('markdown')
```

报告内容包含:
- 执行摘要（数据规模、分析维度）
- 关键洞察（高价值客户占比、平均增长率等）
- 业务建议（基于分析结果自动生成）

## 6. SQL数据库集成

### 6.1 支持的数据库

| 数据库 | 连接字符串格式 | 驱动 |
|--------|--------------|------|
| PostgreSQL | `postgresql://user:pwd@host:port/dbname` | psycopg2 |
| MySQL | `mysql+pymysql://user:pwd@host:port/dbname` | pymysql |
| SQLite | `sqlite:///path/to/database.db` | 内置 |

### 6.2 通过Agent连接数据库

```python
from agent.core_agent import EcommerceAgent

agent = EcommerceAgent()

# 连接数据库
agent.connect_database("sqlite:///my_database.db")

# 查看数据库信息
db_info = agent.get_database_info()
print(f"表数量: {db_info['tables_count']}")
print(f"表列表: {db_info['tables']}")

# 加载表数据
df = agent.load_from_database('orders')
print(f"加载了 {len(df)} 行数据")

# 执行自定义SQL查询
result = agent.execute_sql(
    "SELECT customer_id, SUM(total_amount) as total "
    "FROM orders GROUP BY customer_id ORDER BY total DESC"
)
print(result)

# 对数据库数据执行分析
agent.analyze_data('orders', 'descriptive')
agent.analyze_data('orders', 'rfm',
    customer_col='customer_id',
    date_col='order_date',
    amount_col='total_amount')
```

### 6.3 DatabaseConnector直接使用

```python
from agent.tools.database_connector import DatabaseConnector

db = DatabaseConnector("postgresql://user:password@localhost:5432/ecommerce")

# 列出所有表
tables = db.list_tables()

# 查看表结构
schema = db.get_table_schema('orders')
# 返回: {'order_id': 'INTEGER', 'customer_id': 'VARCHAR', ...}

# 加载表数据（可限制行数）
df = db.load_table('orders', limit=1000)

# 执行查询
df = db.execute_query("SELECT * FROM orders WHERE total_amount > 500")

# 执行写操作
db.execute_sql(
    "INSERT INTO audit_log (action, timestamp) VALUES (:action, :ts)",
    params={"action": "data_export", "ts": "2026-10-21"}
)
```

### 6.4 完整数据库分析流程示例

```python
from agent.core_agent import EcommerceAgent

agent = EcommerceAgent()

# 步骤1: 连接数据库
agent.connect_database("sqlite:///ecommerce.db")
```

## 7. LangChain工具与Plan-and-Execute工作流

### 7.1 LangChain @tool 工具集

借鉴 `react.py` 的设计模式，系统提供9个LangChain标准工具:

```python
from agent.tools.langchain_tools import (
    load_data_from_file,       # 从文件加载数据
    load_data_from_database,   # 从数据库加载数据
    query_database,            # 执行SQL查询
    list_database_tables,      # 列出数据库表
    get_table_schema,          # 获取表结构
    analyze_data,              # 执行数据分析
    generate_visualization,    # 生成可视化图表
    generate_report,           # 生成分析报告
    get_data_summary,          # 获取数据摘要
)
```

**工具调用示例:**

```python
# 从文件加载
result = load_data_from_file.invoke({
    "file_path": "data/orders.csv",
    "file_type": "csv"
})

# 从数据库加载
result = load_data_from_database.invoke({
    "connection_string": "sqlite:///ecommerce.db",
    "table_name": "orders",
    "limit": 1000
})

# 执行SQL查询
result = query_database.invoke({
    "sql_query": "SELECT COUNT(*) FROM orders"
})

# 执行分析
result = analyze_data.invoke({
    "dataset_name": "orders",
    "analysis_type": "rfm",
    "customer_col": "customer_id",
    "date_col": "order_date",
    "amount_col": "total_amount"
})
```

### 7.2 Plan-and-Execute 工作流

借鉴 `pae.py` 的设计模式，实现自动规划→执行→总结的智能工作流:

```python
from langchain_openai import ChatOpenAI
from agent.workflow import run_plan_execute

# 初始化LLM（需要配置API Key）
llm = ChatOpenAI(model="gpt-4", temperature=0)

# 执行Plan-and-Execute工作流
result = run_plan_execute(
    "帮我分析orders数据，执行RFM客户分析，生成销售趋势图和HTML报告",
    llm
)
print(result)
```

**工作流程:**

```
用户请求
   │
   ▼
┌──────────┐     ┌──────────┐     ┌──────────┐
│ Planner  │────▶│ Executor │────▶│ Executor │── ... ──▶ 最终总结
│ (生成计划)│     │ (步骤1)  │     │ (步骤2)  │
└──────────┘     └──────────┘     └──────────┘
                      │                │
                      └── 循环执行 ────┘
                      (直到所有步骤完成)
```

```python
agent.connect_database("sqlite:///ecommerce.db")

# 自定义SQL查询
top_customers = agent.execute_sql("""
    SELECT customer_id, 
           COUNT(*) as order_count,
           SUM(total_amount) as total_spent
    FROM orders
    GROUP BY customer_id
    ORDER BY total_spent DESC
    LIMIT 10
""")
print("Top 10 客户:\n", top_customers)

# 加载完整数据做深度分析
agent.load_from_database('orders')
agent.analyze_data('orders', 'rfm')
agent.generate_report('html')
```

## 11. 常见问题与排错

### Q1: 运行时报错 `ModuleNotFoundError: No module named 'sklearn'`

```bash
pip install scikit-learn
```

### Q2: 图表中中文显示为方块

确保系统安装了对应中文字体:
- Windows: 通常自带 Microsoft YaHei
- macOS: 通常自带 Arial Unicode MS
- Linux: `sudo apt install fonts-wqy-microhei`

### Q3: `resample('M')` 报错

Pandas 3.0 已废弃 `'M'` 频率别名，请使用 `'ME'`:

```python
# 错误
df.resample('M', on='date')
# 正确
df.resample('ME', on='date')
```

### Q4: RFM分析报错 `cannot insert customer_id, already exists`

确保使用命名聚合语法（已在代码中修复）。如果自定义数据，确保 `customer_col` 参数与数据中的列名一致。

### Q5: 数据库连接失败

1. 检查连接字符串格式是否正确
2. 确认数据库驱动已安装（psycopg2/pymysql）
3. 确认数据库服务已启动且网络可达
4. SQLite需确认文件路径存在

### Q6: LangChain工具调用报错

1. 确认已安装 `langchain-core` 和 `langgraph`
2. 使用Plan-and-Execute工作流需配置 `OPENAI_API_KEY`
3. 工具参数类型必须匹配（注意 `Optional[int]` 参数可传 `None`）

### Q7: `streamlit run` 报错

```bash
# 确保在ecommerce_agent目录下执行
cd ecommerce_agent
streamlit run web/app.py
```

### Q8: 如何接入自己的电商数据?

准备CSV文件，包含以下字段（或调整分析参数匹配你的字段名）:

```csv
order_id,customer_id,order_date,total_amount,status
O00001,C0001,2024-01-15,299.00,completed
O00002,C0002,2024-01-16,159.50,completed
```

然后加载:

```python
agent.load_data('my_data.csv', source_type='csv')
agent.analyze_data('my_data', 'rfm',
    customer_col='customer_id',   # 你的客户ID列名
    date_col='order_date',        # 你的日期列名
    amount_col='total_amount')    # 你的金额列名
```
