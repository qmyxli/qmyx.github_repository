# 生活节律小锚 - 使用文档

## 项目简介
生活节律小锚是一个 Python 桌面提醒程序，提供客观的任务管理提醒服务。通过系统弹窗、命令行交互和飞书通知，实现多通道任务提醒。

## 项目结构
```
Second_traeTest/
├── main.py                    # 程序入口文件
├── main_scheduler.py          # Module0: 主控调度器
├── time_calculator.py         # Module1: 时序计算器
├── task_manager.py            # Module2: 任务台账管理器
├── render.py                  # Module3: 消息模板渲染器
├── desktop_notifier.py        # 附加模块：桌面通知工具
├── feishu_notifier.py         # 附加模块：飞书通知工具
├── constants.py               # 常量定义（内置任务、模板等）
├── requirements.txt           # 依赖清单（纯标准库，无需安装）
└── data/                      # 数据目录（自动创建）
    ├── task_status.json       # 任务状态持久化
    └── feishu_config.json     # 飞书配置持久化
```

## 启动方式

### 1. 基础启动（纯标准库）
```bash
python main.py
```

### 2. 增强桌面通知（可选）
如需 Windows 原生弹窗通知，安装依赖：
```bash
pip install winotify
```

## 终端指令说明

### 任务操作
```
暂停 XX任务          # 暂停指定任务提醒
恢复 XX任务          # 恢复指定任务提醒
新增 自定义任务 XX，周期xxx，时间xxx  # 新增自定义任务
删除 XX任务          # 删除自定义任务（内置任务会自动转为暂停）
查看全部任务清单      # 查看所有任务状态
今日任务             # 查看今日任务及完成情况
完成【任务名称】      # 标记任务完成（支持中文方括号【】或英文[]）
```

### 飞书集成
```
设置飞书webhook <地址>   # 设置飞书机器人 Webhook 地址
测试飞书                  # 测试飞书通知是否正常
```

**飞书配置步骤：**
1. 在飞书群聊中添加「自定义机器人」
2. 复制机器人的 Webhook 地址
3. 在程序中输入：`设置飞书webhook <你的webhook地址>`
4. 输入 `测试飞书` 验证配置是否成功

### 程序控制
```
退出程序             # 安全退出程序
退出                # 同上
```

## 新增自定义任务示例

```
新增 自定义任务 早起喝水，周期all，时间08:00
新增 自定义任务 冥想，周期135，时间22:00
新增 自定义任务 整理房间，周期六，时间10:00
```

**周期说明：**
- `all` 或 `每日`：每天执行
- `135`：周一、周三、周五
- `一二三四五六日`：对应星期几
- `12345`：数字形式，1=周一，7=周日

## 弹窗异常排查

### Windows 无弹窗
1. 检查是否安装 winotify：`pip install winotify`
2. 检查 Windows 通知权限：设置 → 系统 → 通知和操作
3. 查看控制台是否有错误提示
4. 程序会在终端同步输出提醒内容，不影响核心功能

### macOS 无弹窗
程序使用 osascript 调用系统通知，通常无需额外配置。

### 定时任务不触发
1. 检查程序是否持续运行（不能关闭终端）
2. 检查系统时间是否准确
3. 查看控制台是否有错误日志

## 技术架构

### 核心模块
- **MainScheduler**：主控调度器，负责流程调度，不执行业务逻辑
- **TimeCalculator**：时序计算器，根据星期/日期筛选今日任务
- **TaskManager**：任务台账管理器，处理指令、权限校验、JSON持久化
- **Render**：消息模板渲染器，严格按模板生成文本
- **FeishuNotifier**：飞书通知器，通过 Webhook 发送消息到飞书

### 多线程并行
定时任务触发时，使用 threading 并行调用计算模块，提升响应速度。

### 文件锁
JSON 读写使用 threading.Lock，防止并发损坏数据。

## 开发约束遵循

✅ 面向对象编程，模块独立 Class
✅ 使用 threading 模拟多 Agent 并行运算

## 常见问题

**Q: 程序关闭后数据会丢失吗？**
A: 不会，所有数据自动保存在 `./data/` 目录。

**Q: 可以修改内置任务时间吗？**
A: 不可以，内置任务时间固定在 constants.py 中，仅允许暂停/恢复。

**Q: 如何配置飞书通知？**
A: 在飞书群聊中添加自定义机器人，复制 Webhook 地址，然后在程序中输入「设置飞书webhook <地址>」。

**Q: 支持多语言吗？**
A: 当前仅支持中文，模板文案在 constants.py 中定义。
